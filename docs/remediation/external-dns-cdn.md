# مستندات تنظیمات دامنه‌های خارجی، DNS و ملاحظات CDN/TLS

این سند راهنمای کامل تنظیم رکوردهای DNS عمومی و پیکربندی شبکه CDN برای پروژه Maktab DevOps است.

---

## ۱. جدول نگاشت رکوردهای عمومی و داخلی

| نام دامنه | نوع رکورد | مقدار هدف (Target) | وضعیت CDN / Proxy | محل اعمال | دلیل فنی و الزامات TLS |
|---|---|---|---|---|---|
| `rezaabolghasemi.ir` | A | `81.12.50.30` | **DNS Only (خاموش)** | پنل DNS خارجی | دامنه اصلی؛ ترافیک وب به سمت Nginx Edge روی VPS1 |
| `wp.rezaabolghasemi.ir` | A / CNAME | `81.12.50.30` | **DNS Only (خاموش)** | پنل DNS خارجی | سرویس وردپرس؛ پورت‌های ۸۰ و ۴۴۳ مستقیماً به VPS1 می‌رسند |
| `app.rezaabolghasemi.ir` | A / CNAME | `81.12.50.30` | **DNS Only (خاموش)** | پنل DNS خارجی | سرویس فرانت‌اند و API بک‌اند؛ پورت‌های ۸۰ و ۴۴۳ به VPS1 |
| `*.maktab.rezaabolghasemi.ir` | A | `10.8.0.1` | **هیچ (کاملاً خصوصی)** | BIND9 سرور VPS1 | کلیه سرویس‌های داخلی (گیتیا، آرگوسی‌دی، گرافانا، پرومتئوس و ...) |

## ۲. هشدارهای حیاتی در خصوص CDN و پروکسی‌های ابری

### الف) عدم فعال‌سازی Proxy برای دامنه‌های خصوصی و پورت‌های غیراستاندارد
- **قانون قطعی:** هیچ‌یک از رکوردهای ساب‌دامین `*.maktab.rezaabolghasemi.ir` نباید در پنل‌های عمومی تعریف یا روی حالت Proxy (ابر روشن در Cloudflare یا ابرآروان) قرار گیرند.
- **علت:** این سرویس‌ها فقط روی IP وایرگارد (`10.8.0.1`) گوش می‌دهند و پورت‌هایی نظیر ۳۰۸۰ (Teleport Proxy) و ۵۰۰۰ (Docker Registry) توسط شبکه‌های CDN عمومی پشتیبانی نمی‌شوند.

### ب) الزامات صدور خودکار گواهی Let's Encrypt (`letsencrypt_enabled: true`)
در صورتی که متغیر `letsencrypt_enabled: true` فعال شود:
1. رکوردهای `wp.rezaabolghasemi.ir` و `app.rezaabolghasemi.ir` باید روی وضعیت **DNS Only** باشند.
2. ترافیک پورت ۸۰ این دامنه‌ها نباید توسط CDN فیلتر یا به HTTPS ریدایرکت شود؛ زیرا Certbot نیازمند دریافت چالش HTTP-01 است.
3. در حالت `letsencrypt_enabled: false` (وضعیت فعلی)، گواهی داخلی با SAN عمومی برای این دامنه‌ها به کار گرفته می‌شود.

## ۳. دستورالعمل اجرایی در پنل DNS کاربر

1. ورود به پنل مدیریت دامنه `rezaabolghasemi.ir`.
2. افزودن رکورد A برای روت دامنه:
   - نام: `@` (یا `rezaabolghasemi.ir`)
   - نوع: `A`
   - مقدار: `81.12.50.30`
   - TTL: `300` (یا خودکار)
   - وضعیت پروکسی: `DNS Only`
3. افزودن رکورد A برای `wp`:
   - نام: `wp`
   - نوع: `A`
   - مقدار: `81.12.50.30`
   - وضعیت پروکسی: `DNS Only`
4. افزودن رکورد A برای `app`:
   - نام: `app`
   - نوع: `A`
   - مقدار: `81.12.50.30`
   - وضعیت پروکسی: `DNS Only`

### تست راستی‌آزمایی:
```bash
dig +short wp.rezaabolghasemi.ir
# خروجی مورد انتظار: 81.12.50.30

dig +short app.rezaabolghasemi.ir
# خروجی مورد انتظار: 81.12.50.30
```
